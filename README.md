# Project 1 - Hello World (ANSI C89)

Projet en C respectant strictement la norme ANSI C (C89 / C90).

## Prérequis

- Compilateur C (`gcc` ou `clang`)
- `make`

## Compilation et exécution

Compiler le projet :
```bash
make
```

Compiler et exécuter directement :
```bash
make run
```

## Tests unitaires

Lancer la suite de tests automatisés :
```bash
make test
```

Nettoyer les fichiers compilés :
```bash
make clean      # Supprime les fichiers objets (*.o)
make distclean  # Supprime les fichiers objets et les exécutables
```
